## Purpose

This playbook sets CIBA's standards for writing consistent, evidence-based funder proposals that reflect our credibility as a regional innovation catalyst.

## Standard Proposal Structure

1. Executive Summary
2. Problem Statement
3. Beneficiaries
4. Program Description
5. Logic Model
6. KPIs
7. Risk Assessment
8. Budget
9. Governance
10. Impact Narrative
11. Sustainability

## Risk Framework Categories

| Category | Focus |
|----------|-------|
| Strategic | Direction and fit |
| Operational | Delivery capacity |
| Financial | Budget and cash flow |
| Stakeholder | Relationships |
| Reputational | Public trust |
| Technical | Implementation |
| Policy/Compliance | Rules and reporting |

## Supported Funders

The proposal engine supports [[ETSI-BC Funding]], [[PacifiCan Funding]], [[Discovery Foundation Funding]], [[InnovateBC Funding]], and [[WeBC Funding]]. Always position ETSI-BC as a funder, never a partner.
